# 高校考场排班管理系统

基于 Win32 GUI 的考场监考排班管理程序（C 语言）。支持教师/考场数据生成、账号登录注册、智能自动排班、按教师查询、排班结果增删改与导出、排班连续性统计。

## 目录结构

| 文件 | 说明 |
|------|------|
| `MainSystem.c` | 主程序（Win32 GUI）：登录/注册、教师管理、智能排班、查询、导出、统计 |
| `TeacherGeneration.c` | 教师数据生成器（控制台） |
| `ExamRoomGeneration.c` | 考场数据生成器（控制台） |
| `build.ps1` | 一键构建脚本 |
| `.vscode/tasks.json` | VS Code 构建任务 |

## 构建

依赖 [MSYS2](https://www.msys2.org/) 的 UCRT64 工具链（默认 `C:\msys64\ucrt64\bin\gcc.exe`）。

在 PowerShell 中运行：

```powershell
.\build.ps1
```

或在 VS Code 中按 `Ctrl+Shift+B`。

> 源码为 UTF-8 编码；编译参数 `-finput-charset=UTF-8 -fexec-charset=GBK` 用于让运行时中文界面正常显示。

## 使用流程

1. 生成样本数据（可选，也可直接使用已有 `.dat`）：
   - 运行 `TeacherGeneration.exe`：`1` 生成教师 → 输入数量 → `8` 保存。
   - 运行 `ExamRoomGeneration.exe`：`1` 生成考场 → 输入数量。
2. 运行 `MainSystem.exe`，注册账号并登录（密码至少 8 位，需同时含大写字母、小写字母、数字、特殊符号）。
3. 点击 **「开始专业对口排班」** 自动生成排班结果。
4. 可对排班结果进行增删改、按教师姓名查询、**「导出考场安排为TXT」**、查看 **「连续性统计」**。

## 数据文件（二进制，运行期生成）

| 文件 | 内容 |
|------|------|
| `teachers.dat` | 教师记录（编号/姓名/院系/职称/特殊要求/已排次数） |
| `exam_rooms.dat` | 考场记录（编号/名称/容量/座位/状态/科目） |
| `schedules.dat` | 排班结果（监考教师/考场详情/匹配情况/修改时间/操作人） |
| `teacher_ext.dat` | 教师扩展审计（最近修改时间/操作人） |
| `users.dat` | 用户账号（用户名/密码） |

## 排班规则

- 大教室（容量 ≥ 50）需要 **6** 名监考，小教室需要 **3** 名。
- 每个考场至少 1 名 **本专业教师**（任课监考）+ 1 名 **巡考**。
- **教授**仅允许监考本专业考场。
- 教师的 **特殊要求**（请假/出差/生病/不可监考，或指定日期不可用）会将其从对应考场排除；支持 `YYYYMMDD`、`YYYY-MM-DD`、`YYYY-MM-DD(原因)`，多项用分号 `;` 分隔。
- 排班优先「同日聚合」并兼顾任务负载均衡。
